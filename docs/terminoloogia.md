# Lähtekoodis kasutatud terminid

| nimetus koodis | eesti termin | seletus |
|---|---|---|
| collocation | kollokatsioon / naabersõna | tavalisest sagedamini koos esinevatest sõnadest moodustuv ühend (nt *kange kohv*, mitte **tugev kohv*) |
| concept | mõiste | tähendus terminibaasi vaates |
| construction | konstruktsioon | vormi ja tähenduse paar, mis võib olla täisskemaatiline (*KES TEGUSÕNA MIDA* tähenduses "keegi teeb füüsilise asjaga mingit tegevust"), poolskemaatiline (*KES taotleb MIDA* tähenduses "keegi taotleb mingit raha/dokumenti") või leksikaalselt küllastunud (sõna *elamisluba* tähenduses "ametlik luba elada teatud riigis")|
| context | kontekst | näitelause terminoloogide vaates (vt *usage*) |
| dataset | sõnakogu | sõnastik või terminibaas |
| definition | seletus / definitsioon | mõiste esitus lühikese kirjeldava lausungina |
| domain | valdkond | temaatiline klassifikaator (nt meditsiin, tehnika) |
| etymology | etümoloogia | keelendi päritolu |
| form | vorm | keelendi üks muutevorm (nt *jooksevad*) |
| gender | sugu | grammatiline sugu |
| government | rektsioon | grammatiline seos lauses, kus põhisõna tähendus määrab laiendi vormi (käände, kaassõnafraasi) (nt *hoolib sõpradest* – kellest? *hirm vananemise ees* – mille ees?) |
| grammar | grammatika | ilmiku grammatiline lisainfo |
| lexeme | ilmik | keelendi ja tähenduse seos ühe sõnakogu piires |
| lexeme relation | ilmiku seos | seos kahe ilmiku vahel |
| meaning | mõiste / tähendus | tähendusüksus, mis seob keelendeid eri sõnakogudes |
| meaning relation | tähenduse seos | seos kahe tähenduse vahel (nt antonüüm) |
| morph | vormi märgend | grammatiline kategooria, mida vorm väljendab |
| paradigm | paradigma | keelendi muutevormistik |
| pos (part of speech) | sõnaliik | sõnade üldisim rühm, mis kajastab nende põhilisi morfoloogilisi, süntaktilisi ja semantilisi sarnasusi ning erinevusi (nt nimisõna, omadussõna) |
| realm | sõnakogu valdkond | Eesti kõrgharidusstandardi valdkond, millesse kuulub sõnakogu |
| register | register | keele kiht või allkeel, millele on iseloomulik teatav sõnavara, süntaks, hääldus vms vastavalt keelekasutuse olukorrale, suhtluseesmärgile (nt ametlik keel, släng) |
| source | allikas | allikas (raamat, artikkel, isik vm) |
| usage | kasutusnäide | näitelause, milles keelend esineb (leksikograafide vaates; terminoloogide vaates vt *context*) |
| value state | väärtusolek | iseloomustab termini sobivust vaadeldava mõiste jaoks (nt *eelistatud*, *väldi*|
| variant | variant | keelendi alternatiivne esituviis (*maaalune* ~ *maa-alune*)|
| word | keelend | iseseisva tähendusega keeleüksus (nt sõna, sõnaühend) |
| word relation | keelendi seos | seos kahe keelendi vahel (nt tuletis, võrdevormid) |
| word suggestion | sõnapakkumine | Sõnaveebi kasutaja saadetud uue sõna pakkumine |
| word type | keelenditüüp | keelendi tüübi klassifikaator (nt lühend, tähis) |
